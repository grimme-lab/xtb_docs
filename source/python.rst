------------------------------------
 Python Integration for the xtb API
------------------------------------

.. warning::
    ``xtb-python`` (`GitHub <https://github.com/grimme-lab/xtb-python>`__, `documentation <https://xtb-python.readthedocs.io>`__) is no longer in active development. We recommend using `tblite <https://github.com/tblite/tblite>`__ instead.

The ``xtb`` program does not provide a Python API directly.
For Python access to the GFN1-xTB and GFN2-xTB methods, we recommend the
actively maintained ``tblite`` Python API.

The ``tblite`` project is hosted on `GitHub <https://github.com/tblite/tblite>`_.
The documentation of the ``tblite`` Python API can be found `here <https://tblite.readthedocs.io>`_.
